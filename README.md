🎥 Clone Disney+
Este projeto é uma recriação da interface do Disney+, desenvolvida para fins de estudo e prática de desenvolvimento web. Ele foca na criação de um clone visualmente fiel ao aplicativo de streaming, utilizando tecnologias modernas.

🧠 Sobre o Projeto
O objetivo deste projeto é replicar a interface do Disney+, explorando habilidades de desenvolvimento front-end e design responsivo. Ele inclui:

Estruturação de páginas com HTML.
Estilização avançada utilizando SCSS, com foco em modularidade e reaproveitamento de estilos.
Interatividade implementada com JavaScript.
🛠️ Tecnologias Utilizadas
HTML — Estruturação de conteúdo.
SCSS — Pré-processador CSS para estilização eficiente.
JavaScript — Adiciona interatividade às páginas.
🚀 Como Executar
Clone o repositório:
bash
git clone https://github.com/FerRufato/clone_disneyplus.git
Navegue até o diretório do projeto:
bash
cd clone_disneyplus
Abra o arquivo index.html no navegador para visualizar o projeto.
